## 1. The project in one page

**Tempest-ARKNET** is a probabilistic launch-weather generator for rocketry Monte Carlo: given a place and a time (or a window), it returns many (typically 100–1024) physically coherent atmosphere samples: wind (u, v, w), temperature, humidity, pressure, density, speed of sound, gust parameters, from the ground to 18 km on 44 fixed heights (10 m near the ground; 10, 50, 100, 150, 200 m … 18000 m). Samples are meant to be fed to a flight simulator or a Monte Carlo harness so the apogee/landing uncertainty from the *air* is realistic. Three Python packages:
- `tempest` — training / calibration / scoring code for the generator (not shipped to users),
- `tempest_weather` — the shipped runtime tool (`api.py`, `_core.py`, `flight/` engine + Dryden turbulence, assets in `tempest_weather/assets*`),
- `tempest_weather_v2` — the user-facing layer: `Launch` (immutable, lazy sample pool), `AtmosphereSet`/`Atmosphere` readers, observation ingestion, trust line, the Monte Carlo harness, site calibration, persistence.

**Goal (the user's words, ratings of 2026-11-08):** raise the system to 9/10 as a Monte Carlo source and 8/10 for apogee accuracy/boosting. The *whole shape* of the distribution must match reality, not only ranges (AUTOPILOT.md "MAIN TARGET"). The system must beat an Earth-GRAM-style baseline (the `gauss` baseline in the scorecard) and the final result is shown with intervals on ERA5, balloons and the 2026 H1 final test (touched ONCE, at the very end).

**The current focus (since 2026-11-08):** ground-level wind (the 10–200 m layer), because only the lowest wind changes apogee much. Everything below in sections 8–10 is about that, about Monte Carlo practice, and about an audit of the code (a Gemini-written bug list plus my own self-audits).

**Modes of the generator:** `ai`/climate (trained conditional network for any date, uses climate indices), `past` (ERA5 profile for that hour + learned balloon-minus-ERA5 residual draws; needs `TEMPEST_ERA5_STORE`), `forecast` (IFS forecast via Open-Meteo + learned forecast error). Mode selection falls back loudly to the climate generator with flags `fallback-mode` / `past-source-not-available` — see the trap in section 5.

## 5. Environment and tooling gotchas (all learned the hard way)

**Shells.** Primary shell tool is Git Bash (POSIX); PowerShell 5.1 is also available (no `&&`, no ternary). Use Unix syntax in Bash (`/dev/null`, forward slashes). `cd /c/Users/Senai/Tempest-ARKNET` first. Windows `taskkill //PID n //T //F` in Git Bash.

**Python.** Always `.venv/Scripts/python`. Scratch/ad-hoc scripts: `PYTHONPATH=. .venv/Scripts/python -W ignore …`. Modules: `-m tempest.<mod>`. Always `open(..., encoding="utf-8")`. Python 3.14.

**Writing edit scripts (important).** Long heredocs with mixed quotes and backslashes break. The reliable pattern: write a Python script with a quoted heredoc into the scratchpad `$TEMP` (here `C:\Users\Senai\AppData\Local\Temp\claude\7aa02992b551459b\cc834717-061f-44dc-bc9f-a3ad10cd0f1f\scratchpad`; the bash variable `$TEMP` also works for files like `$TEMP/fix.py`), read the target with `newline=""`, detect `"\r\n" if "\r\n" in s`, normalise to `\n`, apply replacements **with `assert s.count(anchor) == 1`**, write back with the original ending. **Trap:** inside such scripts a Python escape like `"\n"` or `\\n` inside a *string you insert into a file* can arrive as a REAL newline (the tool layer unwraps it) and corrupt the target (it happened twice: an unterminated `print("` in a script and a broken docstring). Build backslash characters with `chr(92)` or avoid them; verify with `ast.parse` after writing.
Also: `cat >> file <<'EOF'` appends LF to CRLF test files (mixed endings, harmless). `sed -i` on tool-created text is OK for single-line changes.

**Waiting.** `sleep` chains > ~100 s are blocked. To wait for a background job use `timeout 110 bash -c 'until <check>; do sleep 5; done'` or run the command with `run_in_background: true`. Foreground commands that run > 120 s are moved to the background automatically (you get a notification later; do not start a second copy). The **full test suite takes ~200 s** (`tests/`), so run it in the background. The v2 suite (`tempest_weather_v2/tests`) takes ~15–50 s; `tests/test_tool_post.py tests/test_flight_engine.py` ~5 s.

**Test commands.** `.venv/Scripts/python -m pytest tempest_weather_v2/tests -q` (120 passed at last run). Full: `.venv/Scripts/python -m pytest tests -q --ignore=tests/test_flight_sim_readers.py` (242 passed at the gust-cap commit; a few tests were added after). Always run tests before committing code; report what actually happened.

## 7. How the system works

**Pipeline (climate/ai mode):** conditional Engression/CRPS-trained network (4 members; afCRPS + energy score + shear/step losses) trained on ERA5 profiles corrected toward IGRA balloons (`station.py`: per-height linear map + leftover profiles at the two balloon stations EPZ/MAF, 00Z/12Z launches) → **post-stack** at m = 199 per block: spread (range) calibration → seasonal widths / PIT (opt-in assets) → **Schaake shuffle** (rank template from the cell × month×2h bin, template cell 8) → **shear-space map** (rank-preserving high-pass gain on shear) → **lapse-rate quantile map** → thermo (p, rho, a from T, RH, p_sfc) → w head (vertical wind) → **gust law** (Gumbel of the total gust G = max(gust, wind); location linear in wind, wind²/10, season, UTC hour, station flag; scale exp-linear) → `Launch` pool.

**Launch/Window:** `Launch(place, when, mode=…, n=…, seed=…, units="us"|"si", era5_store=…)`; window times are sampled hour by hour (each sample at its OWN random time of the window = right for one launch at an unknown time; the pool flag "window-hours-independent"). New `Launch.sequence(offsets, n)` returns the SAME atmospheres over several hours as one coherent trajectory (copula in time from the ERA5 lag table).

**Observations:** `observe(wind_10m, wind_from_deg, temperature, station_pressure, altimeter, age_hours, distance_km, elevation_diff_m, source)`, `observe_latest` (IEM METAR), `observe_metar`, `observe_hrrr`.
